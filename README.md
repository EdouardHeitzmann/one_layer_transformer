# One-layer transformer class project

[class project instructions](site/index.html) and the
[PyTorch quick reference](site/torch-reference.html).

The following files are all unfinished:

attention.py

embedding.py
encoding.py
loss.py
unembedding.py

Your job is to write these functions and tests to verify them.
